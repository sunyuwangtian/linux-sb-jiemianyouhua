# LINUX SB 现代化界面（油猴脚本）

将论坛主题列表改造成参考图中的三栏卡片布局：左侧主导航、中间主题流、右侧用户与社区概览。脚本只重排页面，不会修改论坛数据。

当前版本：`0.4.1`

## 安装

1. 浏览器安装 Tampermonkey。
2. 新建脚本，将 `linux-forum-beautifier.user.js` 的全部内容粘贴进去。
3. 保存，刷新 `https://linux.sb/`。

## 功能

- 桌面端三栏布局；窄屏自动折叠左栏，移动端变成底部导航。
- 卡片式主题列表、统一圆角、边框、间距与绿色视觉体系。
- 右侧热门话题、版块统计、活跃用户均从当前页面提取。
- “发布新帖”优先调用原站发帖按钮。
- 右下角设置支持紧凑模式、隐藏右栏、本页恢复原样。
- 使用站点原生 `.forum-layout`、`.post-list` 和 `.sidebar`，保留登录、分页、发帖与主题功能。

## 适配提示

脚本按 LINUX SB 当前 bbs1.org v8.6.5 页面结构编写。如果论坛升级后某个区域失效，优先检查 `.forum-layout`、`.forum-main`、`.post-item`、`.sidebar` 和 `.top .bar` 五组选择器。

直接双击 `preview.html` 可查看离线结构预览；头像和 Bootstrap Icons 需要联网显示。
